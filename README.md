# Ktuvit Helper - עוזר הורדת כתוביות

עוזר לחיפוש והורדת כתוביות בעברית מאתר Ktuvit.

## בעיות נפוצות ופתרונות

### 🚨 בעיה: "שגיאת חיבור לשרת Ktuvit"

אם אתה מקבל שגיאה זו, הבעיה כנראה היא שדומיין Ktuvit אינו נגיש:

#### פתרונות:

1. **בדוק חיבור לאינטרנט** - וודא שיש לך חיבור פעיל לאינטרנט
2. **הרץ בדיקת דומיינים**:
   ```bash
   node test-domains.js
   ```
3. **עדכן דומיין בקובץ .env** - אם הבדיקה מצאה דומיין עובד, הוסף אותו לקובץ `.env`:
   ```
   KTUVIT_BASE_URL=https://ktuvit.co.il/
   ```

### הגדרת הטוקן

1. היכנס לאתר Ktuvit במדפדפן
2. פתח Developer Tools (F12)
3. עבור לטאב Application/Storage > Cookies
4. העתק את הערך של הקוקי `Login`
5. הוסף לקובץ `.env`:
   ```
   KTUVIT_TOKEN=u=YOUR_TOKEN_HERE&g=YOUR_GROUP_HERE
   ```

## הרצה

```bash
npm install
npm start
```

האתר יהיה זמין בכתובת: http://localhost:3000

## שימוש

1. בחר סוג תוכן (סרט/סדרה)
2. הכנס שם או IMDb ID
3. עבור סדרות: ציין מספר עונה ופרק
4. לחץ "חיפוש"
5. בחר כתובית להורדה

## בעיות טכניות

- אם האתר לא עובד, בדוק שהטוקן תקין ולא פג תוקף
- אם יש שגיאות חיבור, נסה להריץ `node test-domains.js` למציאת דומיין עובד
- ודא שחיבור האינטרנט פעיל ויציב
